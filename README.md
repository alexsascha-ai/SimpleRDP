# SimpleRDP

A slightly smarter and simple Remote Desktop manager for Windows.

## Why SimpleRDP?

By default, Remote Desktop Connection (mstsc.exe) is not possible to backup the saved passwords and the connection management is not good. 

With SimpleRDP, it is possible to save password and use it on any other Windows PCs.

## ⭐ Features
- Portable
- Backup-able Saved Passwords
- Same user experience while connected to your remote desktop.
- The workflow is similar to WinSCP or HeidiSQL

## FAQ

1. How to Backup?

> SimpleRDP is a portable application, you just need to backup the folder.

2. How to config more settings like screen resolution?

> You can click `Options` in SimpleRDP, it will open the original Remote Desktop Connection application. You can set anything there, but you have to click `Save` at the end. Don't click `Connect`.
